# AI-Generated-Solutions-Of-Proofs-A-Long-Form-Mathematics-Textbook

Hello guys. I am currently studying this book and I can't see any solutions on the internet. Hence, I've decided to use AI to make solutions for the problem sets. As a self-learner, there is no known way for me to check if what I'm doing is correct, unless I would see the solutions. Hence, I use a lot of solutions manual. However, there is no solutions manual available for this book so I've decided to use AI to generate the solutions instead.
